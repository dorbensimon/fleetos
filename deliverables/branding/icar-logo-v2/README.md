# icar — logo v2

A vector identity built by hand (SVG, exact geometry, sources in `build.py`).

**The idea:** an open ring that grows thicker as it moves clockwise, then releases a dot.
- Route: the ring is the fleet's road, and also the "c" in icar.
- Clock: the clockwise motion stands for the time running out on a document's validity.
- The dot: the dot of the "i", in the "valid" color. It closes the loop, meaning everything is under control.

**Colors:** Midnight `#0A1626` · Route `#19C6F0 → #2F5BFF` · Valid `#2EE6A8` · Paper `#F4F6F9`

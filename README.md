# iCar

מערכת לניהול צי רכב לחברות: נהגים, רכבים, מסמכים ותוקפם, טפסים לחתימה דיגיטלית, בדיקות קצין בטיחות, התראות ודוחות.

האתר החי: https://icar-app.com

## מי משתמש

- **מנהל חברה**: מנהל את הנהגים והרכבים של החברה שלו, שולח טפסים לחתימה, עוקב אחרי תוקף מסמכים ומפיק דוחות.
- **נהג**: רואה את הפרטים שלו, את הרכב שלו ואת הטפסים שמחכים לחתימה.
- **בעלים (מנהל המערכת)**: מנהל את כל החברות, תשלומים, הודעות ושבלונות טפסים מוכנות.

## טכנולוגיה

- **אתר**: Expo ו־React Native Web, ב־TypeScript. יש תצוגה למחשב ותצוגה לטלפון.
- **שרת ומסד נתונים**: Supabase (Postgres, הרשאות RLS ו־Edge Functions).
- **חתימות**: DocuSeal.
- **אחסון האתר**: Netlify, שבונה אוטומטית מהענף `main`.
- **שפות**: עברית, אנגלית, ערבית ורוסית (`locales/`).

## הרצה מקומית

```bash
npm install
npm run web
```

האתר נפתח ב־`http://localhost:8081`. צריך קובץ `.env` עם שני משתנים, שלא נשמרים בגיט:

```
EXPO_PUBLIC_SUPABASE_URL=
EXPO_PUBLIC_SUPABASE_ANON_KEY=
```

## פקודות

| פקודה | מה היא עושה |
|---|---|
| `npm run web` | מריצה את האתר מקומית |
| `npm run typecheck` | בודקת טיפוסים בקוד האתר |
| `npm run typecheck:functions` | בודקת טיפוסים בפונקציות השרת (צריך Deno) |
| `npm test` | מריצה את הבדיקות (Jest) |
| `npm run lint` | בדיקת סגנון קוד |
| `npm run build:web` | בונה את האתר לתיקיית `dist` (מה ש־Netlify מריץ) |

## איפה מה

| תיקייה | מה יש בה |
|---|---|
| `screens/` | המסכים: `admin/` למנהל, `driver/` לנהג |
| `components/desktop/` | תצוגת המחשב: דפים, כותרות, טפסים וחתימות |
| `components/owner/` | מסכי הבעלים |
| `components/ui/` | רכיבים משותפים |
| `navigation/` | הניווט בין המסכים |
| `lib/` | לוגיקה, קריאות לשרת, דוחות ותרגום (`lib/i18n`) |
| `locales/` | הטקסטים בכל שפה |
| `supabase/sql/` | שינויי מסד הנתונים, ממוספרים לפי הסדר |
| `supabase/functions/` | פונקציות השרת (Edge Functions) |

## כללי עבודה

- כל שינוי במסד הנתונים נשמר כקובץ ממוספר ב־`supabase/sql/` לפני שהוא מוחל על השרת. הפירוט ב־[supabase/README.md](supabase/README.md).
- שינוי במסד הנתונים, העלאת פונקציה לשרת ומיזוג ל־`main` נעשים רק באישור של דור.
- מפתחות וסודות לא נכנסים לגיט.

הקוד פרטי, וכל הזכויות שמורות.
